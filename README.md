# 📚 Readora
An AI-powered book recommendation web application that recommends books based on users' preferred genre and reading mood using the Content-Based Filtering algorithm.

## ✨ Features
- 📖 Book Recommendation
- 😊 Mood-based Recommendation
- 🎯 Content-Based Filtering
- 🔍 TF-IDF & Cosine Similarity
- 📱 Responsive Web Design

## 🛠 Tech Stack
- Python
- Flask
- HTML
- CSS
- JavaScript
- Pandas
- Scikit-learn
